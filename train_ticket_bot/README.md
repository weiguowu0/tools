# 12306 自动订票（Mac 本地版）

本机运行的 12306 自动抢票工具：扫码登录 → 按车次/日期/席别自动监控余票 → 有余票自动下单 → **到支付前停止**，语音+系统通知提示你手动支付。

## 运行环境

- macOS 12.7.6（本机）
- 已安装的 **Microsoft Edge** 浏览器（不下载 Chromium，直接驱动本机 Edge）
- Python 3.9.6（系统自带即可，无需 Homebrew）

## 首次安装

```bash
cd train_ticket_bot
python3 -m venv .venv
.venv/bin/pip install --upgrade pip
.venv/bin/pip install flask playwright
```

（已安装过则跳过。）

## 启动

```bash
cd train_ticket_bot
./start.sh
```

启动后会自动打开浏览器访问 `http://127.0.0.1:8765`。

## 使用步骤

1. **扫码登录**：点「扫码登录」，会自动弹出 **Edge 窗口**显示二维码，用手机 12306 App 扫一下（不要关闭这个 Edge 窗口）。
2. **加载乘车人**（可选）：登录后点「加载乘车人」，从你账户读取乘车人列表。
3. 填写：路线（出发站→到达站，可多条）、日期、车次、席别优先级、乘车人、票种、开始抢票时间。
4. 点「查询余票」可先看当天有哪些车、余票如何。
5. 点「开始抢票」，程序开始监控；命中车次+席别后自动下单。
6. **订票成功后会弹窗+语音提示，请尽快在 12306（网页或 App）手动支付**。

## 功能说明

- **车次**：多个用逗号/空格分隔，如 `K599, G401`；留空＝任意车次（自动选发车最早的可用车次）。
- **路线**：可填多条「出发站→到达站」，精确匹配——选「石家庄」就只到石家庄站，不会扩展到正定/高邑等同城其它站。
- **席别优先级**：逗号分隔，靠前优先。支持：商务座、特等座、一等座、二等座、高级软卧、软卧、硬卧、软座、硬座、无座、其他。
- **定时抢票**：填「开始抢票时间」（如 `08:00`），程序会自动校准与 12306 服务器的时间差，提前 5 秒预热、到点准时开抢。
- **验证码**：登录/下单途中若出现滑块或点选验证码，程序会**暂停并语音提示**，你在 Edge 窗口里手动完成后自动继续。
- **不自动支付**：只到「提交订单成功」为止，支付完全由你手动完成。

## 重要提示

- 抢票期间请保持 Edge 窗口和网络畅通，不要手动关掉那个 Edge 窗口。
- 12306 有反爬机制，本工具模拟人工节奏（约 0.8 秒刷新一次），若提示「查询过于频繁」请稍候再试。
- 候补、选铺/选座等细节会自动跳过（随机分配铺位/座位）。
- 首次使用建议先用一趟**票源充足**的车次试跑一遍，确认下单流程无误后再用于真正要抢的车次。
- 乘车人姓名、身份证号、登录态等隐私数据保存在运行目录之外的 `../config/`（可用环境变量 `TICKET_CONFIG_DIR` 指定），不会进入源码目录或上传。

## 文件结构

```
train_ticket_bot/
├── app.py            # Web 界面 + API 入口
├── bot.py            # 抢票核心引擎（Playwright + Edge）
├── stations.py       # 车站代码表查询
├── templates/index.html  # 界面
├── data/stations.json    # 车站表（自动生成）
└── start.sh          # 启动脚本

../config/            # 隐私/运行数据（源码目录之外）
├── config.json       # 配置（界面保存后生成）
└── browser_profile/  # 浏览器登录态（持久化，二次启动免登录）
```

## 常见问题

- **提示浏览器已在运行**：上次异常退出残留了 Edge 窗口，手动关闭那个 Edge 窗口后重启 `start.sh`。
- **二维码不显示**：点一下页面上的「扫码登录」标签；仍不显示则关闭 Edge 窗口重试。
- **查询无数据**：确认日期在预售期内（通常 15 天内），或车次号/车站名有误。
